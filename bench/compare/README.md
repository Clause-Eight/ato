# Comparison with other scanners

`compare.py` runs ATO, Microsoft Presidio, scrubadub and HoundDog.ai on the same inputs and writes
`results.json`. The method and why it is built this way are in [ADR 9](../../docs/adr/0009-benchmark-method.md);
the published numbers are in [docs/BENCHMARKS.md](../../docs/BENCHMARKS.md).

## Tests

| Test | Input | Tools |
|---|---|---|
| Values, generated | The bench corpus (`go run ./bench -export`): 30,000 lines, a third with one generated identifier, the rest noise. Seeds 1, 2 and 3. | ATO, Presidio, scrubadub |
| Values, open-source code | Up to 25,000 lines each from the fixtures, migrations, seeders and specs of three open-source applications, plus a 20,000-line generated application log. 3,000 generated values (200 for each of 15 identifiers) are inserted on new lines, written the way the file type writes values; half are named by a keyword, half by a neutral name. | ATO, Presidio, scrubadub |
| Personal data in logs | 320 generated functions in eight languages: personal fields passed to a log call, directly or through a local variable, and harmless fields. | ATO, HoundDog.ai |
| Personal data in logs, harder | 180 generated functions in Python, JavaScript and TypeScript: two-step variables, wrapped values, string methods on the field, templates, defaults, structured logs, error trackers and analytics events (120 to catch), and harmless lookalikes: the length, a verified flag, a masked value and the id (60 to leave alone). | ATO, HoundDog.ai |

HoundDog.ai traces data elements by name into sinks and does not look at values, so it takes part only in the
third test.

## Settings

- **ATO:** defaults (`--min-confidence medium`, every EU country, off-by-default detectors off). The timed run
  is the scored run.
- **Presidio:** `BatchAnalyzerEngine` with spaCy `en_core_web_sm`; the EU country recognisers enabled for English;
  every pattern entity, without the prose recognisers (`PERSON`, `LOCATION`, `NRP`, `ORGANIZATION`, `DATE_TIME`,
  `URL`), which on code flag identifiers and call sites; scores of 0.5 and above.
- **scrubadub:** the default `Scrubber`.
- **HoundDog.ai:** the `hounddogai/hounddog` Docker image, `--network none`, `--no-ai-review`, `--severity all`. The
  image needs git metadata naming a repository, so the script commits the generated files to a local repository
  with a placeholder GitHub remote. A file counts as caught when HoundDog reports a dataflow into a sink.

## Scoring

Per line and per value. On an inserted line, any finding counts as a catch whatever type the tool gave it, which
favours the other tools. Anything reported on any other line is an alarm. In the open-source corpus those
alarms are not all false: real fixtures hold example emails and phone numbers. `results.json` lists the types
of the alarms so they can be read.

## Run

```sh
python3 -m venv venv && venv/bin/pip install -r bench/compare/requirements.txt
docker pull hounddogai/hounddog:latest
mkdir oss && for r in saleor/saleor bagisto/bagisto solidusio/solidus; do git clone --depth 1 https://github.com/$r oss/$(basename $r); done
go build -o ato ./cmd/ato
venv/bin/python -I bench/compare/compare.py --ato ./ato --oss oss --out results
```

`results.json` records each tool's version, the commits of the open-source repositories and the date. Every
value in every corpus is generated by `internal/synth` and belongs to nobody.

The files in `results/` are kept as they were written. Runs before the rename to ATO (2.0, ADR 12) label the
tool `pii-eu` and take the binary with `--pii-eu`; newer runs label it `ato`.
