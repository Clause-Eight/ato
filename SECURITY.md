# Security policy

Report a vulnerability to Clause Eight privately, through **Security → Report a vulnerability** on this repository if you have access, or through your Clause Eight contact.

Include the version (`pii-eu version`), what you ran, and what happened. Never include real personal data in a report; describe the shape of the value instead, or use a synthetic one.

You will get an answer within five working days. Fixes are released as patch versions and noted in the release notes.

In scope: anything that makes pii-eu print, store or send a found value, a crash or hang on crafted input, and problems in the GitHub Action or the release artifacts.
